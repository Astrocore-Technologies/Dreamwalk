# Free player roleplay

The player phase is an authoring window, not a consumable action economy.
Movement, main actions, additional actions, reactions and queued speech do not spend
legacy turn resources. An existing save with zero resources can continue without
an administrative repair. The old fields remain readable for pinned-save compatibility.

End turn still deliberately starts the finite world/NPC batch. It preserves the
active participant, current phase, revision fence, request identity and ordinary
generation consent. Removing player quotas does not permit extra provider calls,
unquoted spending, retries after an uncertain dispatch, or autonomous background turns.

## Established events and real state

Current completed RP is established fiction, not automatically an unsuccessful attempt.
Typed events can coherently open a locked door, transfer or place an owned object,
change a visible NPC's physical condition, relocate an admitted participant, or create
an ordinary prop. Their receipts, state changes and story feed commit atomically.
A failed authority or geometry check rolls back the whole proposal; replay cannot apply
it twice. Another player's body, choices, or private inventory are not available as
RP mutation targets.

Ordinary nonmechanical fiction remains canonical without creating wallet operations or
fake physical receipts. Its prose is explicitly attributed authored fiction and is not
promoted into witnessed NPC evidence. Only admitted typed effects establish tracked
physical outcomes. Natural-language coherence remains a model-quality concern; synthetic
transport tests establish the protocol and state invariants, not universal language accuracy.

Explicit current player RP can introduce a scene or NPC even when the saved flags
for autonomous narrator creation are disabled. Standalone and autonomous generation
still respect those flags. New-location materialization keeps its existing quoted
image/grounding and consent flow; ordinary fictional events need no new picture.
The deterministic mock does not infer arbitrary semantic creation from a generic action.

Speech, questions, quotations and hypotheticals keep their own attribution. Arbitrary
natural language inside an RP segment needs no rigid command grammar. Source utterances
retain their original order and audience even when a post contains many RP fragments.
The fresh compact provider format retains one position for every original segment;
missing or reordered positions are rejected rather than silently dropping actions.

## Geometry and privacy

Map clicks traverse the actual footprint-checked path. The full committed path is retained
(up to the map's 4096 cells), and only presentation accelerates a long animation. Walls,
occupied cells and unverified image geometry are not erased to make a move succeed.
An existing actor cannot be silently overwritten by a new placement. Image-backed
surfaces require suitable grounding; the current floor raster does not prove a tabletop.

Private event text cannot be written into a public entity condition or generated prop.
Physical effects keep their actual visibility independently of the private wording.
Pending speech protects exact source observation IDs from eviction until the reply is
resolved or cancelled, including sources awaiting ordered admission in a long mixed post.
Retention IDs are server-only and confer no audience, knowledge or disclosure permission.
Account erasure removes free descriptions and temporary local aliases while preserving
nontextual mechanics, canonical entity IDs and replay receipts.

## Bounds and compatibility

The old six-segment/two-attempt cap, per-turn impact cap, 1024-post API lifetime cap,
and read-projection item/location/population caps are removed. Explicit authored RP
also bypasses narrative lifetime counters. Standalone and autonomous narration retain
their scene, supporting-NPC and canon-turn caps in both context and commit validation.
Current input length, provider context/output/response limits, map dimensions and geometric
proofs remain technical bounds. Context preparation removes only redundant descriptions
and empty per-segment capability rows; it does not raise the configured financial ceilings.
There is no hidden continuation request when an output cannot fit.

Saved games and legacy resource fields remain readable. Frozen legacy provider bodies
retain their original serialization. An old in-flight story result can still fail its
policy/readset fence after a deployment. It is not silently retried; existing known-cost
settlement rules apply. Before release, check for active old-policy story jobs and allow
them to finish where possible instead of promising seamless completion of every old job.

The game screen no longer shows the two verbose balance/pricing paragraphs or the
turn-resource counters. Current estimates, pending/unknown failures and actual receipts
remain available. Authoring no longer offers inactive player-resource settings. Narrator
behavior is configured separately with bounded freeform guidance; changing it never
rewrites an already prepared provider request.
