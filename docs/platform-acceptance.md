## Milestone interpretation

P0–P3 platform functionality has real persistence and regression coverage. Initial baseline CI now verifies full account/author/two-account invitation and390px browser flows. Additional operator and email follow-up changes must receive their own verification rather than inheriting baseline CI status. P4 is a verification/review gate, not synonymous with a green build. External mail setup, scheduled retention operations and pre-public legal/operational decisions remain visible release responsibilities. None permit silently starting gameplay or charging money.

### Metadata-language addition

Original title/synopsis/source language are preserved. Optional locale variants are selected per field only while their source revision matches; otherwise originals are shown. Original edits invalidate stale variants; correction creates a draft and requires public reapproval. Curated seed variants exist for all three locales. There is no required author translation step and no live automatic translator. This is intentionally narrower than translating the entire story or NPC dialogue.

### Tags and NPCs

Controlled tags use stable IDs and three localized labels, with aliases for old stored strings. Custom tags preserve originals with optional revision-bound variants. NPC public name, description and exposed fields use the same preferred-language/fallback rule; private secrets and biography are excluded from public variants. Source edits invalidate stale translations, and approved adventure snapshots pin the reviewed NPC text. Seed editorial variants are curated, not generated by a live translation provider.
