## Milestone interpretation

P0–P3 platform functionality has real persistence and regression coverage. The later two-mode publication/invitation change passed live API regressions and browser owner-invite/revoke checks. Recipient browser login is blocked by credential handling policy, not bypassed. P4 is a verification/review gate, not synonymous with a green build. Browser capability limitations, email delivery, administrative purge/export operations and pre-public legal/operational checks must remain visible in the handoff. None of these permit silently starting game development or charging money.

### Metadata-language addition

Original title/synopsis/source language are preserved. Optional locale variants are selected per field only while their source revision matches; otherwise originals are shown. Original edits invalidate stale variants; correction creates a draft and requires public reapproval. Curated seed variants exist for all three locales. There is no required author translation step and no live automatic translator. This is intentionally narrower than translating the entire story or NPC dialogue.
