# Ordinary turn admission and known NPC failures

The authenticated owner's End turn can authorize one finite ordinary world batch for that exact round. The command persists its operation alongside the turn transition. Background admission uses native quotes and the existing wallet, ownership, turn-fence and idempotency checks. It does not reuse that authority for another round, location images or a replacement generation.

New batches carry a server-owned `ordinaryTurnConsentVersion: end-turn-v1` marker only after that persisted authority is checked. Known semantic failures in these batches settle their original held reservation at the immutable, verified actual cost and release the unused reserve. The bill proof binds the job, requester, native quote, runtime request, exact context, accepted batch and original tariff. It does not apply model output to the game or make another model call. Terminal callbacks remain idempotent.

Unknown usage, unpriced cache categories, reserve overruns, mismatched ownership/provenance and historical pending holds remain closed. The existing owner-confirmed recovery endpoint remains the only route for those historical known bills. The new policy does not retroactively settle them.

Plan structured output now expresses action-specific target and speech requirements, matching the executable action validator. Previously, the provider schema allowed combinations such as `wait` with a target or `move_to` without a point which the local validator necessarily rejected. Invalid results also record only a bounded validation-stage enum. No raw result, validation message, private context or provider text is added to diagnostics.

Focused coverage includes exact-cost capture and surplus release, finalize replay without a second debit or generation, old-pending and unknown-cost denial, immutable-price/owner/request binding, image-consent exclusion, action-shape agreement, ordinary-round durable consent and quote/body reserve parity. An invalid historical output that was not stored cannot be diagnosed more precisely after the fact.
