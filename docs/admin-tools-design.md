# Remaining administration tools: reference alignment

Scope: references 45–49, reports, taxonomy, model/runtime profiles, Sparks adjustments and audit. This does not change the shared shell, admin overview/users/content/moderation, server authorization, provider configuration contract, credits API or append-only audit/ledger.

## Presentation

- Reports are wide status/reason/decision cards with a separate action. The API supplies a story ID, not a verified title or cover, so neither is invented. Resolved reports retain the disabled review action and original explanation.
- Taxonomy shows existing IDs and all three translations in separate genre/tag tables. Row actions select the same original editor. Search picker, new-entry controls, discard, historical definitions, immutable existing IDs, aliases and revision guard remain intact. There are no cosmetic fake sort/language controls.
- Behavioral profiles and technical runtimes have separate bordered panels. Cards show genuine name, version, description and availability. No portraits or reference configurations are fabricated. The complete director editor is retained after those panels. Existing external-provider restrictions and every configuration field remain intact.
- Credits keep the actual Sparks API, integer inputs, explicit confirmation, idempotency key and exact subunit results. The reference does not authorize relabeling actual credits as demo, inventing balances or executing adjustments.
- Audit remains read-only and shows server-provided timestamps, actor and target identifiers, with unknown action fallback preserved. Search filters loaded rows. A nonmatching query no longer claims the whole journal is empty.
- Local report/model/credits dialogs prevent dismissal or duplicate submission while a request is pending and restore focus on dismissal. No shared Modal behavior changed.
