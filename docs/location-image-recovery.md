# Location image flow and model-access rejection recovery

The location card keeps sharing optional and requires rights attestation. Checking rights prepares a saved-source-bound library search and quote after a short debounce; it does not dispatch a provider request. A concrete model, cost estimate and reserve appear before the Generate button becomes available. Clicking it authorizes only that quote, including the displayed estimate risk. Draft, rights, policy or source changes invalidate the quote. Unknown requests are never automatically repeated.

The old image/details dialog remains an optional budget/library tool. Generated images still require visual review before binding their immutable revision to the location or saved map.

A provider-reported HTTP 403 with model_not_found/model_access_denied proves model-access rejection, **not zero billing**. The same-scope recovery endpoint only accepts an explicit owner attestation of actual charge from provider Usage or support, matching the original Request ID, plus confirmation model access was restored. A read-only review yields a fingerprint; apply verifies the same authorization/policy, hold and liabilities under transaction locks. It appends an immutable recovery receipt, settles the existing reservation once, retains the original attempt/error/diagnostic, and resumes only IMAGE_RESULT_UNKNOWN with no other outstanding liabilities or conflicting stops. It sends no image request. Duplicate operations reconcile through an owner-only GET. Timeout, 5xx, missing diagnostics and other error classes remain blocked. An amount above the original reserve requires separate review and cannot use this narrow recovery.

Do not infer a cost from enabling the model or from an empty Usage display that cannot identify the request. If Usage cannot establish the specific charge, obtain provider support confirmation using the original Request ID. Until then, leave the fields and hold unchanged.

This flow is tested with synthetic transport and a disposable database. It does not establish real provider availability or prove any real billing amount.
